# MG4
## Devlog
The FloatAnimation script works to animate the fish food GameObject moving up and down by using a series of different methods such as Start() and Update() method. In this case, the Start() method starts the movement of the objects and the Update() method works to execute the code by each individual frame to continue to movement of the object. There is also the _timer and _up variables that work to animate the fish food. The _timer variable counts down each frame and once it hits zero, it resets. This flips the boolean variable _up which alternates the object's movement between up and down.
